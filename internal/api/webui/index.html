客户端接入

· 电视 / 平板 / 手机浏览器直接打开播放器全屏,即动态壁纸大屏;
· now 接口返回当前壁纸 JSON(含媒体直链),供 Wallpaper Engine 移动版「URL/网页壁纸」或 Lively 等拉流;
· 媒体直链支持 Range 断点,可被下载器/播放器直接消费。
